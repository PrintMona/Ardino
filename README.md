# Ardino
## Description
This project controls four servo motors using Arduino in Tinkercad.

### Tasks
1. Run all four servo motors using the Sweep example for 2 seconds.
2. After 2 seconds, stop all servo motors at 90 degrees.

## Components
- Arduino Uno
- 4 Servo Motors

## Connections
Servo 1 → Pin 3
Servo 2 → Pin 5
Servo 3 → Pin 6
Servo 4 → Pin 9

## Result
All servo motors sweep for 2 seconds, then stop and hold at 90 degrees.
